### 용어 정리
* // : c++에서 주석 처리할때 사용된다.
* C++: 프로그래밍을 하기위한 수많은 언어중 하나이다.
* 주석 : **인간 독자에게** 코드의 의도를 설명하는데 있다. 
* 컴파일러 : 컴파일러는 컴파일을 해준다. 컴파일은 소스코드를 목적코드로 변경하여 소스코드로부터 컴퓨터가 이해하게 해준다.
* 컴파일 시간 오류 : **~~컴파일 하면서 걸리는 시간~~ => 컴파일 하는 시점에 발생한 오류를 일컫는다.**
* cout : 변수이며 화면에 문자열을 출력할 수 있는 통로이다. <<로 변수를 밀어 넣는다.
* 실행파일 : **컴퓨터가 실행할 수 있는 형태의 파일**
* 함수 : 파라미터를 받을 수 있는 명령어의 집합이다.
* 헤더 : #include A 의 A 파일의 확장자는 주로 .h 이며 헤더로 불린다. 이것은 외부에 작성된 함수의 몸체를 제외한 파라미터 갯수 타입, 반환 타입을 정의한다.
* #inculde : **#include는 미리작성된 코드를 사용할 수 있게 해준다. ex: #include A A 파일의 기능들을 사용할 수 있음.**
* 라이브러리 : **라이브러리는 타인이 작성한 코드이다.**
* 링커 : 링커는 우리가 작성한 소스코드와 사용하고싶은 외부코드를 연결시켜준다.
* main() : 함수이며 프로그램의 시작점이다.
* 목적코드 : 컴파일된 코드로 컴퓨터가 이해할 수 있는 형태의 코드들이다.
* 출력 : 작성한 명령어중 화면에 나오도록 했다면 출력했다고 한다.
* 프로그램 : 코드로 작성된 것
* 소스코드 : 우리가 작성하고 쉽게 이해할 수 있게 작성된 코드이다.
* 구문 : 소스코드에서 #include**와 같은 전처리기 지시어**를 제외한 코드.
* 스트림(stream) : 데이터가 한 방향으로 순서대로 흘러가는 통로.
  화면, 파일, 키보드 등 서로 다른 장치를 똑같은 방법으로 다루기 위한 개념이다.
  이름의 i는 input, o는 output을 뜻한다. (ostream = 출력 스트림)
* 버퍼(buffer) : 스트림 중간에서 데이터를 잠시 모아두는 임시 저장소.
