## summary Ch. 1-3
* 객체 : 타입과 연계된 메모리의 한 영역
* 변수 : 이름을 붙인 객체
* 어떤 변수에 값을 지정하지 않은채 그대로 사용하게되면 해당 객체에 남아있던 쓰레기 값이 사용된다.
* 입력 연산자 하나로 여러 값을 읽을 수 있다.
```cpp
int a = 3
a = 4
a = a + 7
```
    1. 왼쪽의 a의 값을 가져온다.
    2. 4와 7을 더한다.
    3. a에 저장한다.
* 초기화와 대입의 차이 : 초기화는 기존의 값이 없고 타입을 입력해야한다. 반면에 대입은 기존의 값이 있어서 기존의 값을 지워야하고 타입을 입력하지 않아도 된다.
* 바퀴를 재창조하지 말라.
* 변수명을 표준라이브러리에서 제공하는 기능을 이름으로 쓰지 말자.
* 변수명에 타입을 쓸경우 첫글자를 대문자로 하자. (표준 타입과 구분할 수 있음.)
* string 변수 정의시 문자열의 개수까지 저장함.
* int(4bytes), bool, char(1byte), double(8bytes)
* 메모리 상의 비트들의 의미는 이에 접근할 때 사용하는 타입에 전적으로 의지한다.
* 타입 안정성이 없는 경우 (초기화하지 않는 변수를 사용하는 경우)
```cpp
int main() {
    double x;
    double y = x;
    double z = 2.0 + x; 
}
```
* 타입 안전성 확보를 위해 습관적으로 변수를 초기화하고 실행시간 검사를 병행하자.
* 프로그래머의 자유도를 위해 축소 변환을 금지하지 않는다.

* {} 초기화에서 컴파일러가 하는 일이 바로 이 범위 검사입니다.


|타입|범위|칸 수|
|---|---|---|
| signed char | -128 ~ 127 | 256개 |
| unsigned char | 0 ~ 255    | 256개 |
```cpp
char a {100};    // OK    : 100이 -128~127 안에 있음
char b {200};    // ERROR : 200이 범위 밖 → 값이 깨짐
char c {-24};    // OK
int  d {10.9};   // ERROR : 크기 문제가 아니라 소수점이 잘림
```
